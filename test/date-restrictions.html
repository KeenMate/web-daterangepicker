date restrictions

Targeted by e2e/date-restrictions.spec.ts. initial-date pins the visible month; each picker layers a different restriction on top.

min-date 2026-06-10, max-date 2026-06-20
disabled-weekdays="0,6" (Sat + Sun disabled)
initial-date controls the opening month
rolling-year-range="2025-2027" — only 3 years in rolling selector
disabled-dates="2026-06-11,2026-06-12,2026-06-15" (declarative HTML attribute)
disabled-dates set as property — wins over the (different) attribute
