form association

Targeted by e2e/form-association.spec.ts. The control submits a stable ISO value under its name via a light-DOM hidden <input> (web-multiselect's model), exposes el.form, and clears on form.reset(). The value-format attribute (and getValueFormatCallback) control the serialization.

floating, single — default iso format
inline, single (no visible input)
inline, range — iso "start/end"
inline, range + split handling — multiple ISO intervals
inline, single — value-format="json"
inline, range — value-format="array" (name[] start/end)
inline, single — getValueFormatCallback
