🌍 Localization & Custom Names

Built-in locales, week-start-day, and full control over month & weekday labels

Two override surfaces: the month-names and weekday-names HTML attributes take a pipe-delimited (|) list, and the monthNames / weekdayNames JS properties take a string array. When both are set, the property wins.
Indexing is fixed to the JS date number, not the visible order: month-names is [0]=January … [11]=December (matches Date.getMonth()), and weekday-names is always authored Sunday-first: [0]=Sunday … [6]=Saturday (matches Date.getDay()). week-start-day only rotates the display — you never re-order the list.

Built-in Locales

The locale attribute selects bundled UI strings and drives Intl-based month/weekday names. Built-ins: en, de, fr, es (auto detects from the browser).

<web-daterangepicker locale="de"></web-daterangepicker>

Week Start Day

week-start-day takes auto (locale-based) or 0–6 (0=Sunday … 6=Saturday). It rotates which day column comes first — the day cells underneath stay aligned.

Custom Weekday Names v2.0

The weekday-names attribute overrides the header labels with a pipe-delimited list of exactly 7 entries, authored Sunday-first. Here the same Czech list Ne|Po|Út|St|Čt|Pá|So is reused across three different start days — note you never re-order the list; the component rotates it and the labels stay glued to the right days.

<!-- Always Sunday-first: [0]=Sun … [6]=Sat. week-start-day rotates the display. --> <web-daterangepicker week-start-day="3" weekday-names="Ne|Po|Út|St|Čt|Pá|So"></web-daterangepicker>

Custom Month Names v2.0

The month-names attribute overrides month labels with a pipe-delimited list of exactly 12 entries, in calendar order ([0]=January … [11]=December). No rotation — the list is always January → December.

June → "Červen"
June → "06"
<web-daterangepicker month-names="Leden|Únor|Březen|Duben|Květen|Červen|Červenec|Srpen|Září|Říjen|Listopad|Prosinec"></web-daterangepicker>

Full Czech Calendar

Combine locale, week-start-day, month-names, and weekday-names for a fully localized picker. Czech convention starts the week on Monday.

Setting Names via JavaScript

The same overrides are available as array properties — useful when the names come from a translation bundle at runtime. The property wins if an attribute is also present.

const el = document.getElementById('js-names'); // [0]=January … [11]=December el.monthNames = ['Styczeń','Luty','Marzec','Kwiecień','Maj','Czerwiec', 'Lipiec','Sierpień','Wrzesień','Październik','Listopad','Grudzień']; // [0]=Sunday … [6]=Saturday el.weekdayNames = ['Nd','Pn','Wt','Śr','Cz','Pt','So'];

Validation & Fallback

A pipe list must have exactly 12 (months) or 7 (weekdays) non-empty segments. A wrong count or an empty segment is ignored — the picker falls back to locale names and emits a console.warn naming the attribute. Open your DevTools console to see it.

// Console output: // [web-daterangepicker] "weekday-names" ignored: expected exactly 7 // pipe-delimited segments, got 3. Falling back to locale names.
