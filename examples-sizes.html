📏 Calendar Sizing Examples

Examples demonstrating the unified density system for controlling calendar size.

Unified Density System

The component uses a unified density system that scales everything proportionally:

  • Spacing Attributes: spacing="xs|sm|md|lg|xl" - Sets density on the web component
  • Font Attributes: font-size="xs|sm|md|lg|xl" - Alternative syntax (both set density)
  • CSS Classes: .drp-spacing-* or .drp-font-* - Wrapper div approach
  • What Scales: Fonts, spacing, cell sizes, borders, buttons, badges all scale together
  • Semantic Meaning Preserved: --drp-spacing-xs always means "extra small" (value scales, not meaning)

Three Independent Sizing Systems

Control font, spacing, and cell dimensions independently:

  • Font Size: font-size="xs|sm|md|lg|xl" - Controls text size only
  • Spacing: spacing="xs|sm|md|lg|xl" - Controls gaps, padding, margins only
  • Cell Size: cell-size="xs|sm|md|lg|xl" - Controls day cell dimensions and structural sizes only
  • Independence: Each system works independently - combine them any way you like!
