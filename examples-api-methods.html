🔧 API Methods

Control the date picker programmatically using public API methods and properties

1. Show/Hide/Toggle Methods

Control calendar visibility programmatically. These methods are useful for external triggers, keyboard shortcuts, or conditional UI flows.

Calendar state: closed 
const picker = document.getElementById('picker-1');

// Show calendar
picker.show();

// Hide calendar
picker.hide();

// Toggle calendar
picker.toggle();

// Listen for state changes
picker.addEventListener('calendar-open', () => {
    console.log('Calendar opened');
});

picker.addEventListener('calendar-close', () => {
    console.log('Calendar closed');
});

// Tip: Add data-calendar-button to external trigger buttons
// to prevent "click outside" from closing the calendar
// <button data-calendar-button onclick="picker.toggle()">Toggle</button>
void show()
void hide()
void toggle()

2. Get/Set Input Value

Read and write the formatted input value. The format follows the date-format-mask attribute. For range mode, use " - " separator (space-dash-space).

Click buttons to get/set values... 
const singlePicker = document.getElementById('picker-2a');
const rangePicker = document.getElementById('picker-2b');

// Get current input value (formatted string)
const singleValue = singlePicker.getInputValue();
// Returns: "2025-03-15" or empty string

const rangeValue = rangePicker.getInputValue();
// Returns: "01/01/2025 - 01/31/2025" or empty string

// Set input value (must match format mask)
singlePicker.setInputValue('2025-03-15');
rangePicker.setInputValue('01/01/2025 - 01/31/2025');

// Clear input
singlePicker.setInputValue('');
rangePicker.setInputValue('');
string getInputValue()
void setInputValue(value: string)

3. Clear Selection

Clear the current selection and reset the picker to its initial state. This clears both the input value and internal date state.

Selections will be cleared... 
const picker = document.getElementById('picker-3a');

// Clear selection
picker.clearSelection();

// Verify it's cleared
console.log(picker.getInputValue()); // ""

// Clear and reset to specific date
picker.clearSelection();
picker.setInputValue('2025-12-25');
void clearSelection()

4. Reactive Properties (selectedDate, selectedRanges)

Access and modify selection using Date objects. These properties are reactive and trigger re-rendering and events when changed.

Click buttons to interact with reactive properties... 
const singlePicker = document.getElementById('picker-4a');
const rangePicker = document.getElementById('picker-4b');

// Get selected date (single mode)
const date = singlePicker.selectedDate;
// Returns: Date object or null

// Set selected date (single mode)
singlePicker.selectedDate = new Date('2025-12-25');
// Triggers re-render and date-select event

// Get selected ranges (range mode)
const ranges = rangePicker.selectedRanges;
// Returns: [{start: Date, end: Date}] or []

// Set selected ranges (range mode)
rangePicker.selectedRanges = [{
    start: new Date('2025-01-01'),
    end: new Date('2025-01-31')
}];
// Triggers re-render and date-select event

// Clear using properties
singlePicker.selectedDate = null;
rangePicker.selectedRanges = [];
Date | null selectedDate
DateRange[] selectedRanges

5. Calendar State (isOpen)

Read the current calendar visibility state. This is useful for conditional logic, UI synchronization, or analytics tracking.

Calendar state: unknown 
const picker = document.getElementById('picker-5');

// Check if calendar is open
if (picker.isOpen) {
    console.log('Calendar is visible');
} else {
    console.log('Calendar is hidden');
}

// Conditional toggle
function smartToggle() {
    if (picker.isOpen) {
        picker.hide();
        console.log('Closed calendar');
    } else {
        picker.show();
        console.log('Opened calendar');
    }
}

// Track state changes
picker.addEventListener('calendar-open', () => {
    console.log('isOpen is now:', picker.isOpen); // true
});

picker.addEventListener('calendar-close', () => {
    console.log('isOpen is now:', picker.isOpen); // false
});
boolean isOpen (read-only)

6. Picker Instance Access

Access the underlying DateRangePicker instance for advanced features and internal state. Note: This is an advanced API - prefer using web component methods when possible.

Click buttons to explore picker instance... 
const component = document.getElementById('picker-6');

// Access underlying picker instance
const picker = component.picker;

if (picker) {
    // Access internal state
    console.log('Selected start:', picker.selectedStartDate);
    console.log('Selected end:', picker.selectedEndDate);
    console.log('Format info:', picker.formatInfo);

    // Access calendar element
    const calendar = picker.calendar;
    console.log('Calendar element:', calendar);

    // Access configuration (via options object)
    console.log('Mode:', picker.options.selectionMode); // 'single' or 'range'
    console.log('Months to show:', picker.options.visibleMonthsCount);
    console.log('Auto-close:', picker.options.autoClose);
    console.log('Show summary:', picker.options.isSummaryShown);
} else {
    console.warn('Picker not initialized yet');
}
DateRangePicker | null picker (read-only)
⚠️ Advanced API Warning:

Direct picker instance access is provided for advanced use cases. Modifying internal state directly may cause unexpected behavior. Always prefer web component methods and properties when available.

7. Complete API Reference

Full reference of all public methods, properties, and events available on the <web-daterangepicker> component.

Methods

Method Returns Description
show() void Open the calendar popup
hide() void Close the calendar popup
toggle() void Toggle calendar visibility
getInputValue() string Get formatted input value
setInputValue(value) void Set formatted input value
clearSelection() void Clear selection and reset state
setMonthNames(names) void Set custom month names array

Properties

Property Type Access Description
value string Read/Write Formatted input value (alias for get/setInputValue)
disabled boolean Read/Write Disabled state of the picker
selectedDate Date | null Read/Write Selected date (single mode)
selectedRanges DateRange[] Read/Write Selected ranges (range mode)
selectedDates Date[] Read/Write Selected dates (multiple mode)
isOpen boolean Read/Write Calendar visibility state
selectionMode 'single' | 'range' Read/Write Selection mode
dateFormatMask string Read/Write Date format mask (e.g., 'YYYY-MM-DD')
minDate string | undefined Read/Write Minimum selectable date
maxDate string | undefined Read/Write Maximum selectable date
specialDates DecoratedDate[] Read/Write Array of dates with badges/tooltips
disabledDates (Date | string)[] Read/Write Array of disabled dates
picker DateRangePicker | null Read-only Underlying picker instance (advanced)

Events

Event Detail Type Description
date-select DateSelectDetail Fired when date(s) selected
change DateSelectDetail Alias for date-select (same detail)
calendar-open void Fired when calendar opens
calendar-close void Fired when calendar closes
input-change string Fired when input value changes (typing)

TypeScript Interfaces

interface DateRange {
    start: Date;
    end: Date;
}

interface DateSelectDetail {
    formattedValue: string;
    date?: Date;           // Single mode only
    dateRange?: DateRange; // Range mode only
}

// Usage with TypeScript
const picker = document.getElementById('my-picker') as WebDaterangepickerElement;

picker.addEventListener('date-select', (event: CustomEvent<DateSelectDetail>) => {
    console.log('Formatted:', event.detail.formattedValue);

    if (event.detail.date) {
        console.log('Single date:', event.detail.date);
    }

    if (event.detail.dateRange) {
        console.log('Range:', event.detail.dateRange.start, '-', event.detail.dateRange.end);
    }
});

8. Integration Patterns

Common patterns for integrating the date picker with forms, frameworks, and application state.

Form Integration

<form id="booking-form">
    <web-daterangepicker
        id="check-in"
        name="check-in-date"
        selection-mode="single"
        required>
    </web-daterangepicker>

    <button type="submit">Book Now</button>
</form>

<script>
const form = document.getElementById('booking-form');
const checkIn = document.getElementById('check-in');

form.addEventListener('submit', (e) => {
    e.preventDefault();

    const date = checkIn.selectedDate;
    if (!date) {
        alert('Please select a check-in date');
        return;
    }

    // Submit form data
    const formData = new FormData();
    formData.append('check-in', checkIn.getInputValue());

    fetch('/api/booking', {
        method: 'POST',
        body: formData
    });
});
</script>

React/Vue Integration

// React
import { useRef, useEffect } from 'react';

function DatePicker({ value, onChange }) {
    const pickerRef = useRef(null);

    useEffect(() => {
        const picker = pickerRef.current;

        const handleSelect = (e) => {
            onChange(e.detail.formattedValue);
        };

        picker.addEventListener('date-select', handleSelect);
        return () => picker.removeEventListener('date-select', handleSelect);
    }, [onChange]);

    useEffect(() => {
        if (pickerRef.current && value) {
            pickerRef.current.setInputValue(value);
        }
    }, [value]);

    return <web-daterangepicker ref={pickerRef} />;
}

// Vue 3
<template>
    <web-daterangepicker
        ref="picker"
        @date-select="handleSelect"
    ></web-daterangepicker>
</template>

<script setup>
import { ref, watch } from 'vue';

const picker = ref(null);
const selectedValue = ref('');

function handleSelect(event) {
    selectedValue.value = event.detail.formattedValue;
}

watch(selectedValue, (newValue) => {
    if (picker.value) {
        picker.value.setInputValue(newValue);
    }
});
</script>

State Synchronization

// Synchronize with application state
class DateRangeManager {
    constructor() {
        this.picker = document.getElementById('date-range');
        this.state = {
            start: null,
            end: null,
            formatted: ''
        };

        this.init();
    }

    init() {
        // Listen for picker changes
        this.picker.addEventListener('date-select', (e) => {
            if (e.detail.dateRange) {
                this.state.start = e.detail.dateRange.start;
                this.state.end = e.detail.dateRange.end;
                this.state.formatted = e.detail.formattedValue;
                this.onStateChange();
            }
        });

        // Restore state on page load
        this.restoreState();
    }

    onStateChange() {
        // Update UI, save to localStorage, sync with server, etc.
        localStorage.setItem('date-range', JSON.stringify({
            start: this.state.start?.toISOString(),
            end: this.state.end?.toISOString()
        }));

        this.updateDashboard();
    }

    restoreState() {
        const saved = localStorage.getItem('date-range');
        if (saved) {
            const { start, end } = JSON.parse(saved);
            this.picker.selectedRanges = [{
                start: new Date(start),
                end: new Date(end)
            }];
        }
    }

    updateDashboard() {
        // Update other UI elements based on date range
        console.log('Updating dashboard for:', this.state);
    }
}

const manager = new DateRangeManager();
