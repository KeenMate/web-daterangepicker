Control button visibility, create custom presets, and enable multi-range selection

Use attributes to show/hide built-in buttons (Today, Clear, Apply) and the range-mode days/nights summary.

is-today-button-shown="false" is-clear-button-shown="false" is-apply-button-shown="false"
is-today-button-shown="false" is-apply-button-shown="false"

1b. Modal Display Mode (centered overlay)

Set positioning-mode="modal" to render the calendar as a centered overlay with a backdrop scrim instead of anchoring to the input. Helpful on small screens where multi-month layouts horizontally overflow.

positioning-mode="modal" — click input or button to open
visible-months-count="3" — would overflow horizontally on mobile in floating mode; in modal it fits and scrolls vertically
month-layout="grid" grid-rows="2" grid-columns="3" — six months in a centered grid
positioning-mode="floating" mobile-modal-breakpoint="768px" mobile-modal-min-height="500px" — floating when there's enough room, modal when viewport is too narrow OR too short for a 2-month picker (resize the window to test)
// Centered overlay with backdrop — close via Apply, Escape, or backdrop click <web-daterangepicker selection-mode="range" positioning-mode="modal"></web-daterangepicker> // Open programmatically document.querySelector('#picker').isOpen = true; // CSS variables for theming --drp-modal-gap: 16px; /* viewport-edge gap */ --drp-modal-backdrop-bg: rgba(0, 0, 0, 0.45); /* scrim color */ --drp-modal-transition: 150ms ease-out; /* fade timing */

2. Auto-Close Behavior

Control when the calendar automatically closes with the auto-close attribute.

Calendar NEVER auto-closes, not even with Apply button - user must close manually
Closes when selection completes (click, drag-adjust). Note: Multiple mode never auto-closes
Only the Apply button closes the calendar
// Auto-close modes: 'never', 'selection' (default), 'apply' <web-daterangepicker auto-close="never"></web-daterangepicker> <web-daterangepicker auto-close="selection"></web-daterangepicker> <web-daterangepicker auto-close="apply"></web-daterangepicker>

3. Custom Preset Buttons (JavaScript)

Add custom buttons with preset date ranges using the JavaScript API.

Buttons: Last Week, Next Week, Next Month
const picker = document.querySelector('#preset-picker'); // Define custom action buttons with preset date ranges picker.actionButtons = [ { action: 'custom', text: 'Last Week', onClick: ({ picker }) => { const end = new Date(); const start = new Date(); start.setDate(end.getDate() - 7); // Set dates directly on picker instance picker.selectedRanges = [{ start: start, end: end }]; } }, { action: 'custom', text: 'Next Week', onClick: ({ picker }) => { const start = new Date(); const end = new Date(); end.setDate(start.getDate() + 7); // Set dates directly on picker instance picker.selectedRanges = [{ start: start, end: end }]; } }, { action: 'custom', text: 'Next Month', onClick: ({ picker }) => { const start = new Date(); const end = new Date(); end.setMonth(end.getMonth() + 1); // Set dates directly on picker instance picker.selectedRanges = [{ start: start, end: end }]; } }, { action: 'clear', text: 'Clear' }, { action: 'apply', text: 'Apply' } ];

6. Conditional Button Visibility (JavaScript)

Show/hide buttons based on picker state using the isVisibleCallback function.

Apply button only shows when a range is selected (calendar stays open with auto-close="apply")
const picker = document.querySelector('#conditional-picker'); picker.actionButtons = [ { action: 'today', text: 'Today' }, { action: 'clear', text: 'Clear' }, { action: 'apply', text: 'Apply', // Only show Apply when both dates are selected isVisibleCallback: ({ picker }) => picker.selectedStartDate && picker.selectedEndDate } ];

7. Dynamic Disabled State (isDisabledCallback)

Enable/disable buttons dynamically based on picker state.

Apply disabled until both dates selected, Clear disabled when no selection
const picker = document.querySelector('#disabled-picker'); picker.actionButtons = [ { action: 'today', text: 'Today' }, { action: 'clear', text: 'Clear', // Disable Clear when nothing is selected isDisabledCallback: ({ picker }) => !picker.selectedStartDate && !picker.selectedEndDate }, { action: 'apply', text: 'Apply', // Disable Apply until both dates are selected isDisabledCallback: ({ picker }) => !picker.selectedStartDate || !picker.selectedEndDate } ];

8. Dynamic Button Text (getTextCallback)

Change button text dynamically based on picker state.

Apply button shows day count, Clear shows what will be cleared
const picker = document.querySelector('#text-picker'); picker.actionButtons = [ { action: 'today', text: 'Today' }, { action: 'clear', text: 'Clear', // Show what will be cleared getTextCallback: ({ picker }) => { if (!picker.selectedStartDate) return 'Clear'; return 'Clear Selection'; } }, { action: 'apply', text: 'Apply', // Show day count when range is selected getTextCallback: ({ picker }) => { if (!picker.selectedStartDate || !picker.selectedEndDate) return 'Apply'; const days = Math.floor((picker.selectedEndDate - picker.selectedStartDate) / (1000*60*60*24)) + 1; return `Apply (${days} day${days !== 1 ? 's' : ''})`; } } ];

9. Dynamic CSS Classes (getClassCallback)

Apply dynamic CSS classes to buttons based on picker state. Callback can return a single string or array of strings.

Apply button changes color based on completion, Clear button becomes red when selection exists
// Define action buttons with dynamic classes const picker = document.querySelector('#css-picker'); picker.actionButtons = [ { action: 'today', text: 'Today' }, { action: 'clear', text: 'Clear', cssClass: 'clear-button', // Return array of classes getClassCallback: ({ picker }) => { const classes = ['clear-button']; if (picker.selectedStartDate || picker.selectedEndDate) { classes.push('danger'); } return classes; } }, { action: 'apply', text: 'Apply', // Return single string based on validation getClassCallback: ({ picker }) => { const hasComplete = picker.selectedStartDate && picker.selectedEndDate; return hasComplete ? 'apply-ready' : 'apply-waiting'; } } ]; // Inject custom styles into Shadow DOM picker.customStylesCallback = ({ picker }) => ` .apply-ready { background: #10b981 !important; color: white !important; font-weight: 600 !important; } .apply-waiting { background: #d1d5db !important; color: #6b7280 !important; } .danger { background: #ef4444 !important; color: white !important; } `;

10. Dynamic Tooltips (getTooltipCallback)

Show contextual tooltips that change based on picker state. Hover over buttons to see dynamic tooltips.

Tooltips update based on selection state and provide helpful context
const picker = document.querySelector('#tooltip-picker'); picker.actionButtons = [ { action: 'today', text: 'Today', tooltip: 'Jump to today', // Dynamic tooltip shows actual date getTooltipCallback: ({ picker }) => { const today = new Date(); return `Set to ${today.toLocaleDateString()}`; } }, { action: 'clear', text: 'Clear', tooltip: 'Clear selection', // Show different message when nothing to clear getTooltipCallback: ({ picker }) => { if (!picker.selectedStartDate && !picker.selectedEndDate) { return 'No selection to clear'; } return 'Clear the current date range'; } }, { action: 'apply', text: 'Apply', // Show validation help or day count getTooltipCallback: ({ picker }) => { if (!picker.selectedStartDate || !picker.selectedEndDate) { return 'Select both start and end dates'; } const days = Math.floor((picker.selectedEndDate - picker.selectedStartDate) / (1000*60*60*24)) + 1; return `Apply ${days}-day range`; } } ];

11. Combined Features & Priority System

Demonstrates callback priority: *Callback functions override static properties when both are present.

Priority Chain:
• Visibility: isVisibleCallback → isVisible → true
• Disabled: isDisabledCallback → isDisabled → false
• Text: getTextCallback → text → action
• Class: getClassCallback → cssClass → ''
• Tooltip: getTooltipCallback → tooltip → ''
Clear button uses all callbacks simultaneously, demonstrating callback priority
const picker = document.querySelector('#priority-picker'); picker.actionButtons = [ { action: 'today', text: 'Today' }, { action: 'clear', text: 'Clear All', // Overridden by getTextCallback cssClass: 'base-clear', // Overridden by getClassCallback tooltip: 'Static tooltip', // Overridden by getTooltipCallback isVisible: true, // Overridden by isVisibleCallback isDisabled: false, // Overridden by isDisabledCallback // Callbacks take priority over static properties isVisibleCallback: ({ picker }) => picker.selectedStartDate || picker.selectedEndDate, isDisabledCallback: ({ picker }) => !picker.selectedStartDate && !picker.selectedEndDate, getTextCallback: ({ picker }) => { const hasSelection = picker.selectedStartDate || picker.selectedEndDate; return hasSelection ? 'Clear Selection' : 'Clear All'; }, getClassCallback: ({ picker }) => (picker.selectedStartDate || picker.selectedEndDate) ? 'danger' : 'base-clear', getTooltipCallback: ({ picker }) => { if (!picker.selectedStartDate && !picker.selectedEndDate) { return 'Nothing to clear'; } return 'Remove current selection'; } } ];

12. Advanced Custom Actions (Business Use Cases)

Real-world examples of custom buttons for common business scenarios.

Quick access to fiscal quarters, business weeks, and rolling periods
const picker = document.querySelector('#advanced-picker'); picker.actionButtons = [ { action: 'custom', text: 'Last Business Week', tooltip: 'Select Monday-Friday of last week', onClick: ({ picker }) => { const today = new Date(); const dayOfWeek = today.getDay(); const daysToLastMonday = dayOfWeek === 0 ? 6 : dayOfWeek + 6; const lastMonday = new Date(today); lastMonday.setDate(today.getDate() - daysToLastMonday); const lastFriday = new Date(lastMonday); lastFriday.setDate(lastMonday.getDate() + 4); picker.selectedRanges = [{ start: lastMonday, end: lastFriday }]; } }, { action: 'custom', text: 'This Quarter', tooltip: 'Select current fiscal quarter', onClick: ({ picker }) => { const now = new Date(); const quarter = Math.floor(now.getMonth() / 3); const start = new Date(now.getFullYear(), quarter * 3, 1); const end = new Date(now.getFullYear(), quarter * 3 + 3, 0); picker.selectedRanges = [{ start: start, end: end }]; } }, { action: 'custom', text: 'Year to Date', tooltip: 'From Jan 1 to today', onClick: ({ picker }) => { const today = new Date(); const start = new Date(today.getFullYear(), 0, 1); picker.selectedRanges = [{ start: start, end: today }]; } }, { action: 'custom', text: 'Rolling 90 Days', cssClass: 'rolling-period', onClick: ({ picker }) => { const end = new Date(); const start = new Date(); start.setDate(end.getDate() - 89); picker.selectedRanges = [{ start: start, end: end }]; } } ];

13. Icons in Buttons (Font Awesome)

Add icons to buttons using HTML in the text property. Works with Font Awesome, Material Icons, or any icon library.

Note: Since the calendar uses Shadow DOM, you must import Font Awesome inside the shadow root using @import in customStylesCallback. The text property accepts HTML, allowing you to include <i> or <svg> elements.
Visual enhancement using Font Awesome icons
// Font Awesome must be imported into Shadow DOM via @import in customStylesCallback // (not in HTML head, since the calendar uses Shadow DOM) const picker = document.querySelector('#icon-picker'); picker.actionButtons = [ { action: 'today', text: '<i class="fa-solid fa-calendar-day"></i> Today', tooltip: 'Jump to today' }, { action: 'clear', text: '<i class="fa-solid fa-circle-xmark"></i> Clear', cssClass: 'danger-icon' }, { action: 'apply', text: '<i class="fa-solid fa-circle-check"></i> Apply', cssClass: 'success-icon' } ]; // Import Font Awesome into Shadow DOM and style buttons picker.customStylesCallback = ({ picker }) => ` @import url('https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css'); .drp__action { display: inline-flex; align-items: center; gap: 0.375rem; } .success-icon { background: #10b981 !important; color: white !important; } .danger-icon { background: #ef4444 !important; color: white !important; } `;

14. ActionButton API Reference

Complete reference for all ActionButton interface properties. Every callback receives a single ctx (ActionButtonContext) argument — { picker, action, button, data } — so destructure what you need, e.g. ({ picker }) => ….

Core Properties

Property Type Required Description
action 'today' | 'clear' | 'apply' | 'custom' ✓ Button action type. Use 'custom' for custom onClick handlers.
text string ✓ Button label (supports HTML for icons).
onClick (ctx) =>void Custom click handler (required for action: 'custom').

Static Properties

Property Type Default Description
cssClass string '' CSS class name(s) to apply to button.
tooltip string '' Tooltip text shown on hover.
isVisible boolean true Whether button is visible.
isDisabled boolean false Whether button is disabled.

Dynamic Callbacks (Override Static Properties)

Property Type Description
isVisibleCallback (ctx) =>boolean Dynamic visibility control based on picker state.
isDisabledCallback (ctx) =>boolean Dynamic disabled state based on picker state.
getTextCallback (ctx) =>string Dynamic button text based on picker state.
getClassCallback (ctx) =>string | string[] Dynamic CSS classes (single string or array).
getTooltipCallback (ctx) =>string Dynamic tooltip text based on picker state.

Priority System

When both static properties and callbacks are defined, callbacks take priority:

// Callback priority chain: isVisibleCallback → isVisible → true isDisabledCallback → isDisabled → false getTextCallback → text → action getClassCallback → cssClass → '' getTooltipCallback → tooltip → ''

Picker Instance Methods (for onClick handlers)

Method/Property Description
picker.selectedStartDate Get/set start date (range mode).
picker.selectedEndDate Get/set end date (range mode).
picker.selectedDate Get/set selected date (single mode).
picker.renderCalendar() Re-render calendar (call after changing dates).
picker.updateSummary() Update summary text (call after changing dates).
picker.clearSelection() Clear all selections.
