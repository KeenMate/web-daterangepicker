⚡ Events & Callbacks

Learn about the event system and beforeDateSelect callback for validation and control.

Events Fired by the Component

The date picker fires two custom events when a date or range is selected:

Event Names:
  • date-select - Primary event for date selection
  • change - Alias event (fires simultaneously with date-select)

Note: Both events bubble and are composed (cross Shadow DOM boundaries).

Event Detail Structure

// Single mode
{
  formattedValue: "2025-11-17",
  date: Date object
}

// Range mode
{
  formattedValue: "2025-11-17 - 2025-11-24",
  dateRange: { start: Date, end: Date },
  enabledDates: [Date, Date, ...],    // If using 'allow' mode
  disabledDates: [Date, Date, ...],   // If using 'allow' mode
  dateRanges: [DateRange, ...],       // If using 'split' mode
  dates: [Date, Date, ...],           // If using 'split' or 'individual' mode
  getEnabledDateCount: () => number,  // Helper function
  getTotalDays: () => number          // Helper function
}

Listening to Events

// Listening to events
const picker = document.getElementById('my-picker');

picker.addEventListener('date-select', (event) => {
  console.log('Date selected:', event.detail);

  if (event.detail.date) {
    // Single mode
    console.log('Selected date:', event.detail.date);
  } else if (event.detail.dateRange) {
    // Range mode
    console.log('Selected range:', event.detail.dateRange);
  }
});

beforeDateSelect Callback - Validation & Control

The beforeDateSelect callback is invoked BEFORE a selection is finalized. It allows you to validate, block, adjust, or clear selections based on your business logic.

Key Features:
  • Works for both single and range modes
  • Supports synchronous and asynchronous validation
  • Can block, adjust, restore, or clear selections
  • Shows loading overlay during async operations
  • Called AFTER local validation (disabled dates, min/max) passes

Return Value Actions

Action Description Use Case
'accept' Allow the selection as-is Validation passed
'adjust' Modify the selected date(s) Round to business days, snap to availability
'restore' Reject and revert to previous selection Validation failed, keep previous state
'clear' Clear the selection entirely Hard reset on validation failure

Code Examples

// Block weekends
picker.beforeDateSelect = (date) => {
  const isWeekend = date.getDay() === 0 || date.getDay() === 6;
  return isWeekend
    ? { action: 'restore', message: 'Weekends not allowed' }
    : { action: 'accept' };
};

// Adjust to next business day
picker.beforeDateSelect = (date) => {
  const day = date.getDay();
  if (day === 0) { // Sunday → Monday
    const adjusted = new Date(date);
    adjusted.setDate(date.getDate() + 1);
    return { action: 'adjust', adjustedDate: adjusted, message: 'Adjusted to Monday' };
  } else if (day === 6) { // Saturday → Monday
    const adjusted = new Date(date);
    adjusted.setDate(date.getDate() + 2);
    return { action: 'adjust', adjustedDate: adjusted, message: 'Adjusted to Monday' };
  }
  return { action: 'accept' };
};

// Async API validation
picker.beforeDateSelect = async (date) => {
  const response = await fetch('/api/check-date', {
    method: 'POST',
    body: JSON.stringify({ date: date.toISOString() })
  });
  const { available } = await response.json();
  return available
    ? { action: 'accept' }
    : { action: 'restore', message: 'Date not available' };
};

Code Examples

// Minimum nights requirement
picker.beforeDateSelect = (range) => {
  const nights = Math.floor((range.end - range.start) / (1000 * 60 * 60 * 24));
  return nights < 2
    ? { action: 'restore', message: 'Minimum 2 nights required' }
    : { action: 'accept' };
};

// Adjust end date to checkout day (Sunday)
picker.beforeDateSelect = (range) => {
  const endDay = range.end.getDay();
  if (endDay !== 0) { // Not Sunday
    const adjusted = new Date(range.end);
    const daysToSunday = endDay === 0 ? 0 : 7 - endDay;
    adjusted.setDate(range.end.getDate() + daysToSunday);
    return {
      action: 'adjust',
      adjustedStartDate: range.start,
      adjustedEndDate: adjusted,
      message: `Adjusted to Sunday checkout`
    };
  }
  return { action: 'accept' };
};

// Async availability check
picker.beforeDateSelect = async (range) => {
  const response = await fetch('/api/check-availability', {
    method: 'POST',
    body: JSON.stringify({
      start: range.start.toISOString(),
      end: range.end.toISOString()
    })
  });
  const data = await response.json();

  if (data.available) {
    return { action: 'accept' };
  } else if (data.suggestedEnd) {
    return {
      action: 'adjust',
      adjustedStartDate: range.start,
      adjustedEndDate: new Date(data.suggestedEnd),
      message: 'Adjusted to available dates'
    };
  } else {
    return { action: 'restore', message: 'Dates not available' };
  }
};
